🚀 Comece Aqui

A API Pública SysImóveis permite que você integre seus dados de imóveis, leads e integrações com sistemas externos.

Base URL

https://seu-dominio/api/v1/public/

Informações Gerais

  • Protocolo: HTTPS (obrigatório em produção)
  • Formato: JSON
  • Autenticação: API Key via Header
  • Rate Limit: 1000 requisições/hora
  • Versionamento: v1

🔐 Autenticação

Todas as requisições à API devem incluir uma chave de API válida.

Como Gerar uma Chave de API

  1. Acesse o Painel Administrativo
  2. Vá para Configurações → Chaves de API
  3. Clique em "Gerar Nova Chave de API"
  4. Escolha um nome (ex: "Integração CRM")
  5. Copie e guarde a chave de forma segura

Como Usar a Chave

Inclua o header X-API-Key em todas as suas requisições:

curl -X GET https://seu-dominio/api/v1/public/properties \
  -H "X-API-Key: sua-chave-aqui" \
  -H "Content-Type: application/json"
⚠️ Segurança: Nunca compartilhe sua API Key publicamente. Se a chave for comprometida, revogue-a imediatamente no painel.

📡 Endpoints Disponíveis

Propriedades / Imóveis

GET/properties

Lista todas as propriedades da empresa

Parâmetros de Query:
page (int, opcional) - Número da página (padrão: 1)
limit (int, opcional) - Itens por página (padrão: 20, máx: 100)
status (string, opcional) - Filtrar por status (active, sold, archived)
Exemplo de Requisição:
curl -X GET "https://seu-dominio/api/v1/public/properties?page=1&limit=20" \
  -H "X-API-Key: sua-chave-aqui"

Leads / Contatos

GET/leads

Lista todos os leads/contatos

Parâmetros de Query:
page (int, opcional) - Número da página (padrão: 1)
limit (int, opcional) - Itens por página (padrão: 20, máx: 100)
status (string, opcional) - Filtrar por status (new, contacted, qualified)
Exemplo de Requisição:
curl -X GET "https://seu-dominio/api/v1/public/leads?page=1&limit=20" \
  -H "X-API-Key: sua-chave-aqui"

POST/leads

Cria um novo lead/contato

Body (JSON):
name (string, obrigatório) - Nome do lead
email (string, obrigatório) - Email
phone (string, opcional) - Telefone
message (string, opcional) - Mensagem do lead
source (string, opcional) - Origem do lead (facebook, website, etc)
Exemplo de Requisição:
curl -X POST "https://seu-dominio/api/v1/public/leads" \
  -H "X-API-Key: sua-chave-aqui" \
  -H "Content-Type: application/json" \
  -d '{
    "name": "João Silva",
    "email": "joao@example.com",
    "phone": "(21) 99999-9999",
    "message": "Interessado no apartamento em Copacabana",
    "source": "facebook"
  }'
Resposta de Sucesso (201):
{
  "success": true,
  "message": "Lead criado com sucesso",
  "data": {
    "id": 123,
    "name": "João Silva",
    "email": "joao@example.com",
    "phone": "(21) 99999-9999",
    "status": "new",
    "created_at": "2024-04-22T16:00:00Z"
  }
}

💡 Exemplos de Uso

JavaScript / Node.js

const apiKey = 'sua-chave-aqui';
const apiUrl = 'https://seu-dominio/api/v1/public';

// Listar propriedades
fetch(`${apiUrl}/properties?page=1&limit=20`, {
  method: 'GET',
  headers: {
    'X-API-Key': apiKey,
    'Content-Type': 'application/json'
  }
})
.then(response => response.json())
.then(data => console.log(data))
.catch(error => console.error('Erro:', error));

// Criar um lead
fetch(`${apiUrl}/leads`, {
  method: 'POST',
  headers: {
    'X-API-Key': apiKey,
    'Content-Type': 'application/json'
  },
  body: JSON.stringify({
    name: 'João Silva',
    email: 'joao@example.com',
    phone: '(21) 99999-9999',
    message: 'Interessado em imóvel',
    source: 'website'
  })
})
.then(response => response.json())
.then(data => console.log(data))
.catch(error => console.error('Erro:', error));

Python

import requests
import json

api_key = 'sua-chave-aqui'
api_url = 'https://seu-dominio/api/v1/public'
headers = {
    'X-API-Key': api_key,
    'Content-Type': 'application/json'
}

# Listar propriedades
response = requests.get(f'{api_url}/properties?page=1&limit=20', headers=headers)
properties = response.json()
print(json.dumps(properties, indent=2))

# Criar um lead
lead_data = {
    'name': 'João Silva',
    'email': 'joao@example.com',
    'phone': '(21) 99999-9999',
    'message': 'Interessado em imóvel',
    'source': 'website'
}
response = requests.post(f'{api_url}/leads', headers=headers, json=lead_data)
result = response.json()
print(json.dumps(result, indent=2))

PHP

$apiKey = 'sua-chave-aqui';
$apiUrl = 'https://seu-dominio/api/v1/public';

// Listar propriedades
$options = [
    'http' => [
        'method' => 'GET',
        'header' => "X-API-Key: $apiKey\r\nContent-Type: application/json\r\n"
    ]

$context = stream_context_create($options);
$response = file_get_contents("$apiUrl/properties?page=1&limit=20", false, $context);
echo json_encode(json_decode($response), JSON_PRETTY_PRINT);

// Criar um lead
$leadData = [
    'name' => 'João Silva',

    'phone' => '(21) 99999-9999',

$options = [
    'http' => [

⚠️ Códigos de Erro

Código Significado Descrição
200 OK Requisição bem-sucedida
201 Created Recurso criado com sucesso
400 Bad Request Requisição inválida (parâmetros faltando ou inválidos)
401 Unauthorized API Key não fornecida ou inválida
403 Forbidden Você não tem permissão para acessar este recurso
404 Not Found Recurso não encontrado
429 Too Many Requests Limite de requisições excedido
500 Internal Server Error Erro no servidor (entre em contato com suporte)

Exemplo de Erro

Requisição sem API Key:
{
  "error": "API Key não fornecida",
  "message": "Header X-API-Key é obrigatório"
}
API Key Inválida:
{
  "error": "API Key inválida",
  "message": "A API Key fornecida não é válida ou expirou"
}

📞 Suporte

Dúvidas Frequentes

Como renovar minha API Key?

Você pode revogar uma chave antiga e gerar uma nova no painel administrativo em Configurações → Chaves de API.

Qual é meu rate limit?

O padrão é 1000 requisições por hora. Se precisar de um limite maior, entre em contato com suporte.

Posso usar a API sem API Key?

Não. Todas as requisições obrigatoriamente precisam incluir uma API Key válida no header X-API-Key.

Como integrar com Facebook/WhatsApp/Webhook?

Use o endpoint POST /leads para enviar informações de leads capturados em outras plataformas.
